# Droplet ORM

Code-generation-based Go ORM for MySQL, Redis 8.2+ / Valkey 9.0+, ClickHouse and NATS JetStream (CDC and tasks).

Module: `github.com/DropletLive/orm`, package `orm`. Forked from `github.com/latolukasz/fluxaorm/v2` at v2.4.4; see "Migrating from fluxaorm" in `CLAUDE.md`.
